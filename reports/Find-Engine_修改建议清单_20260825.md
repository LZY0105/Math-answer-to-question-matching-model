# Find-Engine 修改建议清单

[中文](Find-Engine_修改建议清单_20260825.md) | [English](Find-Engine_Modification_Checklist_20260825.md)

以下顺序按“先消灭自信错配，再提高召回与速度”排列。

## P0：发布阻断项

- [ ] **对文档角色做双向门控**
  - 当前只检查右侧是否为答案册；必须同时要求左侧为习题册、右侧为答案册。
  - 左侧为答案册时直接整书拒绝，不能进入题目索引和 `matchPage`。
  - 自动化覆盖：Q→A 允许；A→A、Q→Q、A→Q 全部拒绝。

- [ ] **在阶段 0 前增加“配套书身份”门控**
  - 新增整书级状态：`VERIFIED_PAIR`、`UNKNOWN_PAIR`、`REJECTED_PAIR`。
  - 未达到 `VERIFIED_PAIR` 时，题号相同不能直接给 `HIGH`。
  - `sharedAlphabetOverlap/indexesComparable` 只能说明两段文本是否可比较，不能证明两本书配套；2023 习题与错误的 2025 答案仍得到 0.9638 重叠率。
  - 建议组合信号：归一化书名/年份/版本、题号集合与章节结构、跨全书均匀抽取的同题号内容相似度，以及同题号相似度相对随机错位样本的裕量。
  - 扫描版没有内容证据时应返回 `UNKNOWN_PAIR` 并要求 OCR，不能因题号重合放行。

- [ ] **区分“章节书签”和“题目书签”**
  - `1.2 一元函数微分学`、`2.7 线性变换` 必须归入 section，不能归入 question。
  - 优先识别明确题目标记，如 `例题 1.78`、`题 2.187`、`Problem ...`。
  - 结合节点深度、子节点类型、题号密度、单调连续性和页跨度分类；跨几十页的节点不能作为一道题。
  - 若目录只有章节而没有题级节点，题目索引应为空并进入正文/OCR路径。

- [ ] **把稀疏文本层识别为扫描版**
  - 质量判定不能只看抽样字符是否含中文，还要看 `有文字页数 / 总页数`、每页字符数和覆盖均匀度。
  - 本次 2025 习题为 465 页、65 行、609 字符，必须判定为 `SCANNED` 或 `SPARSE_LAYER`。
  - `describeUnusable` 不应因为存在 18 个章节条目就跳过扫描版判断；只有“可靠题级书签”才能绕过 OCR。

- [ ] **把 OCR recogniser 真正接入 PdfWorkspace**
  - `createTextSource` 已有 recogniser 接口，但当前应用路径没有调用。
  - 对扫描版按需 OCR 当前页并缓存；后台可逐页扩展索引，避免首次打开就 OCR 465 页。
  - OCR 未配置/失败时返回明确的 `OCR_REQUIRED`，且已接受匹配必须为 0。
  - OCR 后仍需通过题号结构、章节和配套书身份门控，不能把 OCR 输出直接视为可信题目。

## P1：无书签准确率与性能

- [ ] **实现此前确认的完整逐题匹配流程**
  - 单题模式先根据用户点击位置或显式题号确定习题边界，只读取当前题；全书模式从第一题开始逐题生成候选，但不能使用一旦出错就连锁错位的不可回滚贪心。
  - 答案册只建立一次不可变索引；先用配套身份、题号、章节和倒排索引筛选，再计算内容证据。
  - 提取当前题内**所有完整数学表达式**为保留次数、顺序和位置的 `FormulaSet`；括号、分式、根号、上下标、积分/极限边界和矩阵结构必须完整。
  - 高置信度要求 `FormulaSet` 全部覆盖且无强冲突；只对上其中一部分不得通过。表达式残缺、OCR 截断或无法确定题目边界时只能复核或拒绝。
  - 每个完整表达式匹配成功后，才比较它左右各三个字符作二级消歧；三字符上下文不能单独触发匹配，也不能救回公式不完整或冲突的候选。
  - 执行习题→答案与答案→习题双向校验；顺序一致时只作为窗口加速，顺序重排时改用全局一对一分配。
  - 高置信度答案进入已占用集合；中低置信度仅暂存并允许回滚；不从原始索引中删除题目或答案。

- [ ] **把 `unidentifiable` 计入假阳性，而不是排除在精确率之外**
  - 报告同时给出：`verified_precision = correct / identifiable` 和 `strict_precision = correct / accepted`。
  - 发布验收以严格精确率为准。
  - 本次“无习题书签、有答案书签”的严格精确率为 544/732 = 74.3%，不能标为 100%。

- [ ] **收紧正文题号解析**
  - 2023 习题正文解析出 730 个候选，而金标准只有 508 个；需要排除目录、章节号、页码、年份和小问。
  - 结合 PDF 行坐标/字号/字体信息，不只使用纯文本行首正则。
  - 低密度孤立题号、超长页跨度、与章节序列冲突的条目默认拒绝。

- [ ] **收紧答案正文分段**
  - 无书签答案册解析出 1,235 个候选，而真实答案只有 508 个。
  - 优先使用“解/答/答案/例题”前缀、连续题号序列、章节边界和解答块终止条件。
  - 对重复题号必须有内容或章节证据；只有编号不能显示答案。

- [ ] **不要把 `LOW` 当作已匹配答案直接展示**
  - `LOW` 应作为候选或“需要确认”，默认不跳转答案页。
  - 只有 `HIGH/MEDIUM` 且通过整书身份门控后，才能进入正式已匹配状态。

- [ ] **优化无习题书签路径的候选集合**
  - 建立题号倒排索引，先按规范化层级题号和章节缩小范围，再计算内容相似度。
  - 预计算数学片段、运算符上下文和归一化文本，避免逐页重复扫描整本答案。
  - 当前该路径 p95 380.9 ms、最大 1,534.6 ms；建议桌面 p95 < 150 ms，且不得依赖超时来维持拒配。

## P2：回归测试、指标与文档

- [ ] **把本次四份 PDF 加入外部真实语料回归清单**
  - 语料仍可不提交仓库，但 CI/本地验收必须支持明确路径。
  - 固定文档指纹、页数、题级书签数和题号范围，避免拿错版本。

- [ ] **新增整书错配矩阵**
  - Q23→A25、Q25→A23：整书拒绝，accepted=0，HIGH=0。
  - A23→A23、A25→A25、A23→A25、A25→A23：全部整书拒绝。
  - Q23/Q25 的同年、跨年双习题组合：全部整书拒绝。
  - A→Q 反向组合：全部整书拒绝。

- [ ] **无书签测试改为全书运行**
  - 不再只按每 8/16 页抽样；全书 368/372 页可在桌面完成。
  - 所有 accepted 结果必须落入独立书签金标准，否则算假阳性。

- [ ] **新增扫描版章节误识别回归**
  - 对当前 2025 习题，在 OCR 未接入时应返回 `OCR_REQUIRED`，accepted=0。
  - `1.2 一元函数微分学` 和 `2.7 线性变换` 必须被分类为 section。
  - OCR 接入后，573 个题号的首个阶段目标建议为唯一召回 ≥95%、严格精确率 100%；随后再提高召回，不能以错配换覆盖。

- [ ] **新增题内公式全集与顺序重排回归**
  - 多公式题只有部分公式匹配：不得 `AUTO_MATCH`。
  - 全部完整公式匹配后才执行逐公式左右三字符比较；上下文单独相似不得放行。
  - 任一公式缺失、截断、上下标/积分界限/矩阵元素冲突：必须 `REVIEW` 或 `REFUSED`。
  - 答案顺序与习题顺序不同时仍能一对一正确分配，同一答案不得重复使用。
  - 人为扰动一个早期高置信度配对后，中低置信度分配能够回滚，后续题不得连锁错位。

- [ ] **更新 README 指标口径**
  - 解释 `verified_precision` 与 `strict_precision` 的区别。
  - 不再用排除 `unidentifiable` 后的 100% 代表全部已接受结果。
  - 明确 2025 扫描版在未配置 OCR 时不可用。

- [ ] **输出可诊断的整书拒绝原因**
  - 建议统一 reason code：`LEFT_ROLE_INVALID`、`RIGHT_ROLE_INVALID`、`PAIR_IDENTITY_MISMATCH`、`PAIR_IDENTITY_UNKNOWN`、`OCR_REQUIRED`、`NO_QUESTION_LEVEL_INDEX`。
  - 日志记录触发门控的证据摘要，但不记录受版权保护的完整题目文本。

## 建议验收线

- [ ] 现有 138 项测试继续全部通过。
- [ ] 2023 双书签：唯一召回 508/508，严格精确率 100%。
- [ ] 所有跨书错配：整书拒绝率 100%，accepted=0，HIGH=0。
- [ ] 所有双答案、双习题、答案→习题组合：整书拒绝率 100%。
- [ ] 扫描版未配置 OCR：`OCR_REQUIRED`，accepted=0。
- [ ] 扫描版配置 OCR：首阶段唯一召回 ≥95%，严格精确率 100%。
- [ ] 四种无书签组合分别报告严格精确率、唯一召回、拒绝率和 p95；不得隐藏 `unidentifiable`。
- [ ] 无习题书签路径桌面 p95 < 150 ms，最大值不触及算法超时。
- [ ] 多公式题自动匹配时题内完整 `FormulaSet` 覆盖率为 100%，结构冲突数为 0；部分覆盖不得输出 `AUTO_MATCH`。
- [ ] 左右各三个字符只在对应完整公式匹配后参与消歧，不得独立改变拒绝结论。
- [ ] 顺序重排、缺题和增题语料保持全局一对一；已占用状态可回滚且原始索引不删除。
