实施入口：[复审版优化方案](Android匹配引擎优化方案-复审版.md)。原方案作为历史版本保留。两份都是未实施方案。

实测报告：[真机性能评估报告](真机性能评估报告.md)。受测包为 2026-09-13 21:25:35 安装的 1.4.0 调试包，首次查询 9048.9 ms（1 次主要样本），最长主线程任务 4905 ms；10 次热查询 7.2–22.9 ms。并非全书准确率、峰值内存或稳定 p95 验证。

- 后续动画版本由维护者确认沿用此计算基线；不声称重新测量新版。

- 发布版替换了失效的本地路径链接，device.json 仅去掉随机安装路径。evidence-manifest.json 同时记录原件和公开副本的校验值。
