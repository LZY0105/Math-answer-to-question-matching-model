# 教材形状合成语料

本语料由 [generate-textbook-data.mjs](generate-textbook-data.mjs) 生成，用于替代 v2 合成语料。标签由本仓库自编的语法产生，渲染器收到的字符串就是标签本身，因此标签按构造正确。未使用任何第三方 OCR 权重、预训练视觉模型或教师模型；MathJax 与 sharp 只作为渲染工具。

生成命令：

~~~powershell
node ocr/generate-textbook-data.mjs --output tmp/formula-textbook-v1 --train 40000 --validation 2000 --test 2000 --ex-px 10.5 --cover 400
~~~

## 1. 为什么重做

v2 合成语料与部署图像的形状不一致。在五本考研教材的 600 张真实裁图上实测，真实公式又宽又扁：宽高比中位 7.57、p90 20.62，墨迹高度中位 33 像素，笔画中位 2.25 像素。v2 的语法是深度递归，产出的是又高又方的嵌套塔，宽高比约 2.8。

一张中位真实裁图放进 768 × 768/3 的画布会按宽度约束放大约 2.8 倍，高度只占画布的三分之一，其余是白边。这既浪费算力也损失信息，而且它是语法问题，不是渲染参数问题。

## 2. 生成规模与构成

| 项目 | 数值 |
| --- | --- |
| 样本总数 | 44,000（train 40,000 / validation 2,000 / test 2,000） |
| 磁盘占用 | 290 MB |
| 词表 | 138 项 |
| 随机种子 | 20260927 |
| 渲染尺度 | ex-px 10.5 |
| 单条 token 上限 | 150（含 BOS/EOS 后不超过模型的 160） |
| 接受率 | 74%（59,321 次尝试） |

按来源分：覆盖载体 11,838、通用语法 29,354、高等代数模板 2,127、实变函数模板 478、偏微分方程模板 203。

## 3. 与真实分布的对照

同一套测量脚本、同样按墨迹外框裁切后统计：

| 指标 | 真实教材裁图 | 本语料 | 旧 v2 |
| --- | --- | --- | --- |
| 宽高比 中位 | 7.57 | 7.70 | 约 2.8 |
| 宽高比 p10 | 2.41 | 2.46 | — |
| 宽高比 p90 | 20.62 | 18.44 | — |
| 裁切后宽 中位 | 276 | 266 | 926 |
| 裁切后高 中位 | 33 | 30 | 329 |
| 笔画粗细 中位 | 2.25 | 2.20 | — |
| 墨迹占比 中位 | 0.077 | 0.093 | — |

宽高比中位与笔画粗细的偏差均在 2% 以内。p90 偏低 11%、墨迹偏浓 21%，即极宽公式略少于真实、排版略紧于教材，属于欠representation 而非分布错误。

## 4. 控制形状的两处设计

**宽度来自关系链，不来自递归深度。** 语法以「关系链 → 项 → 因子」为骨架，长度分三档抽取：20% 短式（常含一个高结构）、42% 一到两个关系、38% 三到六个关系。单一链长无法同时覆盖 p10 的 2.4 与 p90 的 20.6。

**高度由预算控制，不由概率控制。** 分式、带限积分、大算符、矩阵、分段式各记一个单位，每条公式只发 0 到 2 点额度，长链模式至多 1 点。只调概率压不住高度：两次独立抽样仍会嵌套相乘，分式套分式有 5 ex 高，这几本书里几乎不印。

## 5. 词表覆盖

模板是有限清单，去重会在语料填满之前耗尽它们，学科符号因此只剩个位数行。第一版语料有 30 个 token 出现不足 300 行，`\liminf` 仅 2 行、`\oplus` 为 0 行——出现两次的 token 等于模型没见过。

现改为先跑覆盖阶段：30 个载体模板每个保底 400 条，且每个载体内嵌现场生成的子表达式，因此不会像纯符号替换那样饱和。

结果：**138 项词表中，低于 300 训练行的 token 为 0 个**，最稀有者 300 行。

## 6. 一处 TeX 拼接缺陷及其修正

TeX 控制词会吞掉其后的字母。把 `\geq` 与以 `q` 开头的项直接拼接会得到 `\geqq`——渲染出的是另一个符号；`\to` 接 `x` 得到 `\tox`，严格渲染器直接拒绝。v1 语料 40% 的低接受率即源于此。

这无法用正则在成品字符串上判定：需要分隔的字母按构造与控制词的词尾无法区分，贪婪匹配只会回溯进词内部，把 `\det(` 变成 `\de t(`。现按本生成器实际发出的命令集合做最长前缀匹配：`geqq` 中认出 `geq` 并切分为 `\geq q`，`det` 完整匹配则不动。接受率随之从 40% 升至 74%。

## 7. 分区与校验

标签文本与 PNG 字节在全语料范围内唯一，分区是对该唯一集合的划分，因此标签与图像的跨分区隔离由构造保证。独立复核（只读写出的三个 jsonl）结果：

| 检查项 | 结果 |
| --- | --- |
| 唯一 id 数 = 样本总数 | 44,000，通过 |
| id 跨分区 | 0 |
| 相同标签跨分区 | 0 |
| 相同图像哈希跨分区 | 0 |
| 抽查 800 条的缺图 / 哈希不符 / token 数不符 | 0 / 0 / 0 |
| validation 与 test 中未见于训练的 token | 0 |

## 8. 适用范围

本语料对齐的是真实教材的形状、笔画与符号覆盖，它仍然是合成数据。上一轮的结果表明分布之外仍有差距：合成验证集 96.9%，真实 PDF 裁图 37.5%。

当前增强只有光度（对比度、轻微模糊、噪声），没有几何变换，也没有模拟扫描噪点、倾斜与字体差异。因此本语料不足以单独支撑真实教材准确率的结论；该结论需要独立标注的真实裁图，相关工作清单见 `Desktop\训练集\transcription\`。
